# Maintainer entry

Use [the repository map](repository-map.md) to find the owning surface and
[the release process](release-process.md) to ship changes with inspectable proof.
[README grounding](readme-grounding.json) records the primary examples fetched
through MCP and the specific design choices applied to the public entry point.

[Proposal: initiative lifecycle contract](proposal-initiative-lifecycle-contract.md)
is a draft for one `phase` plus `next_command` view across the whole loop; it is
not normative until shipped through `spec/`.

The normative contract is `spec/` plus conformance. User guides explain that
contract; tests establish bounded behavior; release evidence records an actual
observation. None substitutes for the others.
